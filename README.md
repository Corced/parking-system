# Classic Parking System

Aplikasi konsol berbasis TypeScript yang dirancang untuk membantu pengelolaan data parkir kendaraan secara terstruktur. Aplikasi ini menyediakan fitur Create, Read, Update, Delete, dan Search untuk mempermudah pencatatan serta pengelolaan informasi kendaraan.

## Fitur Aplikasi

- **Create:** Menambahkan data kendaraan baru.
- **Read:** Menampilkan seluruh data kendaraan dan detail berdasarkan ID.
- **Update:** Memperbarui informasi kendaraan berdasarkan ID.
- **Delete:** Menghapus data kendaraan berdasarkan ID dengan konfirmasi.
- **Search:** Mencari data kendaraan berdasarkan kata kunci dan filter tertentu.

## Cara Instalasi dan Menjalankan Program

1. Pastikan Node.js dan Git sudah terinstal.
2. Clone repository:
   `git clone https://github.com/Corced/parking-system.git`
3. Masuk ke folder project:
   `cd parking-system`
4. Instal dependencies:
   `npm install`
5. Jalankan aplikasi:
   `npx ts-node src/index.ts`
